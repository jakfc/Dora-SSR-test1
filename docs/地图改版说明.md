| 项 | 旧 | 新 |

| 地图宽 `MAP_WIDTH` | 5400 | **7600** |
| 左侧山脉 | 大罗山（`DALUO_MOUNTAIN`） | **取消**，换成开阔海面 + 西岸滩头 |

**要点**

- 取消左侧山脉：`LandmarkId` 里已删掉 `DALUO_MOUNTAIN / PADDY_FIELD / OUTER_SALT_FLAT / COAST_SPAWN`，
  远景层不再画山，改为海天一线 + 东西两头的倭船帆影（`farDraw` 里的多边形桅帆）。
- 东西对称：`SPAWN_WEST_X: 260` / `SPAWN_EAST_X: 7420`，敌人从两头刷出（`Enemy` 的 `side: 'W' | 'E'`）。
- 两道门：西面是**内城水门** `INNER_GATE`（新），东面仍是**东门瓮城** `EAST_GATE`。
  两路敌人**都必须先破内城水门**才能进城打宗祠（`Enemy.updateAI` 第 3 步）。
- 开局站位：主角在宗祠西侧 `PLAYER.startX`，三名闲散族丁也在宗祠前（`spawnVillager(HALL.x - 120/-60/-20)`）。
  宗祠位于 `x=2620`，在 `FORTRESS` 已探明区内，所以开局屏幕不会一大片黑。
- 每人守哪条线：族丁按 `id` 单双号分守东西（`Villager` 里 `id % 2`），
  西线用 `GameState.getWestDefenseX()`（内城水门），东线用 `getFrontDefenseX()`（东门/敌台）。

## 2. 战争迷雾（Fog of War）

| 分区 id | 名称 | 范围（x / 宽） | 开局 |
| --- | --- | --- | --- |
| `WEST_WILD` | 西滩荒野 | 600 / 1650（→2250） | 未探明 |
| `FORTRESS` | 永昌堡 | 2250 / 1450（→3700） | **已亮**（堡城：水门、宗祠、东西门全在里面） |
| `EAST_WILD` | 东滩荒野 | 3700 / 3350（→7050） | 未探明 |
| `EAST_SEA` | 东海 | 7050 / 550（→7600） | 未探明 |

- 数据在 `GameConfig.FOG_ZONES`，状态在 `GameState.explored`。
- 渲染在 `GameScene.ts`：`fogLayer` + `fogDraw` 画半透明墨蓝矩形（`0xdd0b1220`），
  每个未探明分区挂一个「未 探 明」标签。
- **分层**：`fogLayer` 是 `worldLayer` 的子节点，插在**地标之后、塔与人之前**。
  于是雾盖住未探明的地形与建筑，却**不会把踏进雾里的族丁吞掉**（《王国：新大陆》里
  农民走进黑区仍然看得见）。
- **只有主角王叔杲算探路**（“君主一人开路”），走到距边界 `FOG_REVEAL_RADIUS`（120）以内即揭开整片分区，
  弹出「探明新地界：××」提示；族丁私自走过去**不算**。
- 迷雾层不单独跟镜头，它跟着 `worldLayer.x` 一起滚。

## 3. 开垦（荒地 → 熟田）

水田与盐田**开局是 0 级「荒地」，不产出**，必须投银开垦。

| 等级 | 含义 | 水田产出/趟 | 盐田产出/趟 |
| --- | --- | --- | --- |
| Lv0 | 荒地 | 0 | 0 |
| Lv1 | 青苗 / 盐畦 | +15 | +120 |
| Lv2 | 熟田 / 成畦 | +30 | +240 |
| Lv3 | 沃野 / 白盐堆 | +45 | +360 |

- 配置：`GameConfig.RECLAIM = { MAX_LEVEL: 3, COST: {PADDY:120, SALT:150}, SECONDS: {PADDY:11, SALT:13}, … }`。
- 第 `n+1` 级造价 = `COST[kind] × (level + 1)`；工期 = `SECONDS[kind] × (1 + 0.25 × level)`（**越熟越慢**）。
- 盐田等级在灶户交盐时结算：`Villager.deposit()` 里 `SALT_FETCH.tripSilver + level × RECLAIM.SALT_YIELD_PER_LEVEL`。
- 只有 `landLevelOf(id) > 0`（`isLandReady`）的地块才真正投产。

## 4. 每个升级都有单独的建模

升级不再是「同一个方块改数字」——每一级换的是**另一座楼**。

| 建筑 | 模型 id | 级数 |
| --- | --- | --- |
| 宗祠 | `lm_ANCESTRAL_HALL` / `_lv2` … `_lv5` | 1–5（`ANCESTRAL_HALL_MAX_LEVEL: 5`） |
| 内城水门 | `lm_INNER_GATE` / `_lv2` / `_lv3` / `_broken` | 1–3 + 破损 |
| 东门瓮城 | `lm_EAST_GATE` / `_lv2` / `_lv3` / `_open` / `_broken` | 1–3 + 开/破损 |
| 箭楼 / 炮台 | `tower_arrow_lv2` / `tower_cannon_lv2` 等 | 未建 / Lv1 / Lv2 |
| 民居 | `lm_house_plot` / `lm_house_lv1` … `lm_house_lv3` | 空地 + 1–3 |
| 水田 | `lm_paddy_lv0` … `lm_paddy_lv3` | 0–3 |
| 盐田 | `lm_saltflat_lv0` … `lm_saltflat_lv3` | 0–3 |

生成脚本：`python tools/gen_level_models.py`（1x + 严格 2× `@2x`，全部落在 `assets/buildings/`）。
切换逻辑集中在 `GameScene.ts` 的 `landmarkArtId(id)`：只按等级/状态返回模型 id，缺图自动回退色块。

## 5. 节奏

| 项 | 值 | 说明 |
| --- | --- | --- |
| `GAME_SPEED` | **0.6** | 全部 `dt` 统一乘它（移动 / 攻速 / 工期 / 招募 / 采集） |
| `DAY_DURATION` | **66 秒** | 白天更长，够跑完一圈 |
| 一局 | ≈ 8 夜 × 66 ÷ 0.6 ≈ **14.7 分钟** | 见 `docs/节奏与镜头.md` |

镜头更近：`CAMERA_VIEW_WIDTH/HEIGHT = 960 / 520`（配合 `Screen.camZoom`）。

## 6. 参考《王国：新大陆》的机制对照

| 《王国》的设计 | 本作落地 |
| --- | --- |
| 投金币给乞丐 → 变成村民 | **投银**：宗祠募丁（花钱）、民居添丁（慢速自增） |
| 村民白天干活、黄昏往回跑 | 白天劳作，`DUSK_RETURN_SECONDS` 前必须回城，**夜里未归会被倭寇杀** |
| 投金币修墙 / 造塔 | 投银升级宗祠 / 加固水门与东门 / 解锁敌台（都要工期 + 挥锤动画） |
| 金币撒给怪物买命 | **`[F]` 撒银退敌**（小兵退散，大将只是被眩晕） |
| 地图逐步探索 | **战争迷雾**：**主角**走到哪亮到哪，族丁不代为探路 |
| 农田要开垦才会长 | **开垦**：水田/盐田 0→3 级 |
