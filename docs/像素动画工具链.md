### 编译踩过的两个坑（复现时要带）

1. **Skia 编译报 `jpeglib.h` 找不到**：官方参数只写了 `skia_use_system_libpng/webp/icu/...=false`，
   漏了 **`skia_use_system_libjpeg_turbo=false`**。该开关默认在 `is_official_build=true` 时为 **true**，
   于是 GN 不生成 libjpeg-turbo 的头文件路径，`SK_CODEC_DECODES_JPEG` 却仍然打开 → 必炸。
   加上这个参数后 Skia 一次编过。
2. **Aseprite 链接报 `SKSHAPER_LIBRARY-NOTFOUND`**：Skia 只产出 `skia.lib` 等，
   `FindSkia.cmake` 仍会去找 `skshaper`；按该版本 Skia 的导出目标补齐即可。

另外：Windows 商店版 `python3.exe` 是占位桩（返回 9009），要让 GN 用真解释器，
需 `--script-executable="...\pyshim\python3.exe"`。

## 二、无头用法（AI 可直接驱动）

```bash
AS="/c/Users/jakfc/AppData/Local/Programs/Aseprite/aseprite.exe"

# 批量量帧：内容框 / 脚底线（脚本见下）
"$AS" -b --script measure.lua

# 导出精灵表 + JSON 元数据（给程序读）
"$AS" -b walk.aseprite --sheet walk.png --data walk.json --format json-array

# 导出动画帧
"$AS" -b walk.aseprite --save-as "f_{frame}.png"
```

### ⚠️ `app.open` 会把后续同族编号的文件一起读成多帧

实测：`app.open("player_attack_01.png")` → `#frames = 3`（把 01/02/03 读成 3 帧）；
`player_walk_03.png` → `#frames = 4`（03/04/05/06）。
所以**量单帧内容必须只取第 1 帧**：

```lua
local img = app.open(path).layers[1].cels[1].image   -- 只取第 1 帧
for y = 0, img.height - 1 do
  for x = 0, img.width - 1 do
    if app.pixelColor.rgbaA(img:getPixel(x, y)) > 16 then ... end
  end
end
```

按这个写法，Aseprite 与 Pillow 的测量结果**逐像素一致**（同帧同点 RGBA、不透明像素数都对得上）。

## 三、逐帧显示倍率（`src/config/FrameScale.ts`）

### 现象
AI 出的动作帧常常比站姿矮一截（`player_attack_01` 内容高 118，站姿 176 —— 只有 6.7 成）。
`assets` 里是原图，程序按**站姿**算的 padding 去显示，于是同一族里：
出拳时人突然变小、走路帧一高一低。

### 机制
`Assets.artSpriteFromPath` 里按 `frameScaleOf(path)` 把该帧的**绘制尺寸**乘以一个系数：

```
k = (该帧内容高 / 人高基准) 的倒数
   —— 即把这一帧的内容拉到和站姿一样高；锚点不动，所以脚底仍钉在地上
```

- 系数表由 `tools/gen_frame_scale.py` 自动生成（只写表，不改图）；
- `tools/match_family_scale.py` 只**报告**哪些帧需要重绘，不动文件；
- 目标值写在 `Assets.ts` 的 `PERSON_TARGET` 里，`tools/audit_person_scale.py` 对账。

### 铁律
**逐帧只允许平移（脚底线 + 躯干中轴），绝不允许按躯干高度裁剪再缩放。**
历史上按躯干高裁剪导致攻击/麒麟步帧整体缩了 13%，就是这条规矩的由来。

## 四、相关工具

| 工具 | 作用 |
| --- | --- |
| `tools/gen_frame_scale.py` | 生成逐帧显示倍率表 |
| `tools/match_family_scale.py` | 报告哪些帧该重绘（不改图） |
| `tools/fix_sprite_frames.py` | 严格按 `1x` 重建 `@2x`（防止 @2x 比 1x 小导致动画中途变小） |
| `tools/normalize_scale.py` | 按**站姿**给整族一个统一系数（不逐帧各自缩放） |
| `tools/audit_person_scale.py` | 与 `PERSON_TARGET` 对账 |
