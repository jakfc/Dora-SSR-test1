# 音频接入说明

音频文件放在 `assets/audio/` 下，分两类：

| 目录 | 内容 | 播放方式 |
| --- | --- | --- |
| `assets/audio/bgm/` | 5 首循环背景乐 | 流式播放（整首循环，切换时交叉淡入） |
| `assets/audio/sfx/` | 19 个短音效 | 内存播放（`Audio.play`，播完自动回收） |

## 全部音频清单

**BGM**（`audio/bgm/`）

| 文件 | 什么时候响 |
| --- | --- |
| `bgm_title.wav` | 标题页 |
| `bgm_day.wav` | 白天经营（每夜战罢、翌日整备时切回） |
| `bgm_night.wav` | 入夜防守（`startNightPhase` 起） |
| `bgm_victory.wav` | 通关结算 |
| `bgm_defeat.wav` | 城破结算 |

**SFX**（`audio/sfx/`，19 个）

| 事件 | 文件 |
| --- | --- |
| 挥刀 / 箭出 / 箭中 | `sfx_sword_slash` / `sfx_arrow_shoot` / `sfx_arrow_hit` |
| 炮响 / 炮中 | `sfx_cannon_fire` / `sfx_cannon_hit` |
| 麒麟步 / 冲击波 | `sfx_qilin_punch` / `sfx_shockwave` |
| 受伤 / 敌亡 | `sfx_hurt` / `sfx_enemy_die` |
| 银两 / 撒银 | `sfx_coin_silver` |
| 抡锤施工 / 锄地 | `sfx_build_hammer` / `sfx_farm_hoe` |
| 升级竣工 / 招到人 | `sfx_upgrade` / `sfx_recruit` |
| 集结鼓 / 夜袭号角 / 开门 | `sfx_drum_rally` / `sfx_wave_horn` / `sfx_gate_open` |
| 界面点击 / 悬停 | `sfx_ui_click` / `sfx_ui_hover`（悬停音效暂未接线） |

## 代码在哪

- `src/audio/Sound.ts` —— 唯一出口，和 `src/config/Assets.ts` 一个套路：
  - `soundPreload()` 启动时登记（`init.ts` 调用）；
  - `soundTick(dt)` 每帧走时钟，`init.ts` 的主循环里调用，用于给音效限流；
  - `soundBgm('day'|'night'|'title'|'victory'|'defeat')` 播 BGM，重复调用同一首不会重头开始；
  - `soundSfx('sword_slash')` 之类播音效；
  - `soundSetMuted(true|false)` / `soundToggleMuted()` —— 拧 `Audio.globalVolume`，HUD 底栏最左那颗「音♪ / 音×」按钮就是它。
- **缺文件不会崩**：`Content.exist` 先探测，文件不在就静默跳过，并在 `soundReportMissing()` 里报告；
  想换音效只要把同名 `.wav` 放到对应目录即可，**不用改代码**。
- **同名音效限流**：`SFX_GAP` 表给每类音效定了最小间隔（缺省 `SFX_GAP_DEFAULT`＝0.05 秒），
  间隔内同一个音效只播一次，避免一群族人同时挥刀时把扬声器糊掉。
- 还有 `soundSfxNear(id, x, viewCenterX, viewWidth)`：只播「视野内」的音效（远处打斗不吵）。

## 想调什么

| 想要的效果 | 改哪里 |
| --- | --- |
| 整体音量 / 静音 | 游戏里点 HUD 的「音♪」；或 `Sound.ts` 的 `soundSetMuted` |
| 某类音效太密 | `Sound.ts` 的 `SFX_GAP`（单位秒，越大越稀）与 `SFX_GAP_DEFAULT` |
| BGM 交叉淡入更慢/更快 | `Sound.ts` 里 `Audio.playStream(path, true, 1.0)` 第三个参数（秒） |
| 只关音效 / 只关音乐 | `soundSetSfxEnabled(false)` / `soundSetBgmEnabled(false)` |
| 换掉某一首/某个音 | 直接覆盖 `assets/audio/` 下的同名 `.wav` |

> 音频重新生成用 `python tools/generate_audio_assets.py`；
> 跑起来自检（文件是否找得到、能不能开播）用 `python tools/_probe_audio.py`。
