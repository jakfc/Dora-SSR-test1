# 美术工程清单（Aseprite）

每个 `.aseprite` = 一个素材族：**多帧族**是走路/攻击这类逐帧动画，**单帧族**是一个静态素材。工程目录由 `tools/aseprite_import.py` 从`assets/sprites/` 生成（目录被 git 忽略，可随时重建）。
改完用 `tools/aseprite/导出回游戏.bat` 写回游戏（会同时重建 @2x、跑一遍无损校验）。
