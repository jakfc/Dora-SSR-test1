## 一、总规则（每张都适用）

| 项 | 值 |
| --- | --- |
| 画布 | 人 = **128×192**；头目 = **192×256**（不许改尺寸） |
| 脚底线 | 人 **y = 185**；头目 **y = 249**（脚底必须落在这一行，±1px） |
| 内容高 | **保持该族正常帧的高度**（见下表"内容高"列），别改 |
| 四边留白 | **≥6px**（不许有像素贴到画布边缘） |
| 朝向 | 主角/村民**朝右**；倭寇**朝左**（一致，不要改成朝右） |
| 背景 | 透明 |
| 命名 | 原文件名，不要改名、不要加后缀 |

改完放进 `assets/sprites/<目录>/`，然后让我跑一遍：
`python tools/fix_sprite_frames.py --apply` → `python tools/gen_frame_scale.py` → `python tools/audit_anim_flow.py`。
