# 永昌堡（DoraSSR）QA 实机测试修改清单（10 项）

请根据以下在实机运行截图（`.agent/vision/*.png`）与场景树导出（`docs/_scene_dump.txt`）中发现的 10 个问题，逐项排查 `src/` 下对应代码（重点关注 `src/scenes/GameScene.ts`、UI/HUD、视差背景与迷雾渲染等）并完成修复：

1. **修复地面贴图高度不一导致的“地底白洞”与垂直拼接断层**
   - 现状：画面中下方地面泥土层左右高度不统一，左侧偏浅沙土层下方直接露出一大块灰白色矩形空洞，右侧深褐色石块土层更深，交界处呈垂直一刀切。
   - 目标：统一所有地面变体贴图高度与锚点，确保地下填充/延展遮罩铺满至视口最底端，消除露底白块与生硬垂直断层。

2. **调整地面水面倒影透明度与范围**
   - 现状：所有建筑（宗祠、民居、水门、盐课司）下方都有整块半透明镜像倒影，直接叠在地下泥土和草根上，显得像沉在透明玻璃地板里。
   - 目标：仅在真实水域（护城河、水田、水门下方等）保留适度水面倒影，普通石板/泥土路面取消穿透式建筑倒影，改用贴地接触阴影。

3. **恢复天空渐变、云层与远山视差背景**
   - 现状：建筑背后目前几乎是一片纯深蓝色，远山、云彩、天际线剪影未正常呈现；`_scene_dump.txt` 显示 `2560x320` 条带集中在 `y=5` 且存在同坐标正反重叠（`scaleX 1.00` 与 `-1.00` 同在 `1462,5`、`4022,5`）。
   - 目标：修复视差背景层的 `y` 偏移、层级顺序、平铺去重与缩放比例，使天空、云层、远山剪影铺满建筑上方视野。

4. **修正“未探明”战争迷雾边界**
   - 现状：开局画面左侧约 1/4 被深色半透明迷雾盖住，直接压暗了`敌台箭楼 Lv.1` 与左半边地面，且压住了新手操作提示。
   - 目标：开局默认点亮玩家核心主城区域（至少完整覆盖西侧敌台箭楼以内），并柔化迷雾边缘过渡，避免硬边黑墙切开城内建筑。

5. **解决建筑、角色名与 UI 文字重叠遮挡**
   - 现状：
     - 画面中央 `民居 Lv.1`、`（可住 2 人）`、主角名 `王叔杲`、地面 `炮台空位（未建）` 四重文字叠在一起；
     - 左侧新手提示白字压在箭楼浅色屋檐上导致 `[E] 十八...`、`[J] 麒麟步` 等无法辨认；
     - 右上角 `提前入夜` 按钮遮住背后建筑名称，下方 `(白银命脉)` 悬空。
   - 目标：为新手引导/操作提示提供固定底框或安全位置；错开建筑标签、角色名与地面空位提示的纵横向高度（或改为靠近交互时再显示次级标签）；避免 HUD 按钮与世界/建筑文字重叠。

6. **优化超宽屏（`3440x1369`）摄像机缩放与视口上下比例**
   - 现状：`VIEW 3440.0 x 1369.0` 下 `CAMZOOM` 为 `3.518`，导致地下泥土层占了将近 45% 的屏幕高度，有效视野被挤在中间窄带；顶部状态栏字号偏小且全挤在左上角。
   - 目标：按视口高度合理计算 `CAMZOOM` 与 `GROUND_Y` 的屏幕占比（地下保留约 18%~25% 即可），让顶部 HUD 随窗口宽度自适应分布。

7. **清理同坐标重复渲染的建筑与地面精灵**

   - 目标：排查地标/房屋刷新与平铺代码，在重建或刷新贴图前清理旧子节点或复用已有节点，消除重复绘制。
